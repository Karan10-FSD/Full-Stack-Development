This is Example of Image Mapping





Image Mapping is an HTML feature that allows different areas of a single image to become clickable. Instead of making the entire image work as one hyperlink, image mapping enables multiple clickable regions within the same image. Each region can link to a different webpage, file, email address, or another location within the website.

Image mapping is useful when a single image contains several objects or sections that should perform different actions. For example, an image of a world map can allow users to click on different countries to learn more about them. Similarly, an image of a computer can let users click on the monitor, keyboard, or mouse to view information about each component.
